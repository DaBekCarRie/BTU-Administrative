# เอกสารอ้างอิงอยู่นอกระบบเหตุการณ์

ตาราง `reference_documents` และไฟล์แนบของมัน**เขียนตรงได้** ไม่ผ่าน `recordEvent()`
และไม่มีเหตุการณ์ใดเกิดขึ้นเมื่อเพิ่ม แก้ หรือแนบไฟล์

## ทำไม (อย่า "แก้" ให้ผ่านระบบเหตุการณ์โดยไม่อ่านตรงนี้)

ADR-0001 บังคับว่าการเขียนข้อมูล**คน**ต้องผ่านเหตุการณ์ เพราะสถานะของคนเปลี่ยนตามเวลา
และทีมต้องตอบได้ว่า "เทอมที่แล้วคนนี้อยู่สถานะอะไร" ประวัติคือตัวข้อมูล

เอกสารอ้างอิงไม่มีคุณสมบัตินั้นเลย
- **ไม่ผูกกับคน** — ตารางสอบของปีหนึ่งเป็นของทั้งทีม ไม่มีไทม์ไลน์ของใครให้ไปแสดง
- **ไม่มีสถานะที่เปลี่ยนตามเวลา** — ไม่มีผ่าน/ไม่ผ่าน ไม่มีขั้นตอน มีแค่ "มีไฟล์นี้อยู่"
- **ไม่ใช่ข้อมูลส่วนบุคคล** — จึงไม่ต้องมีร่องรอยว่าใครเปิดดู (ต่างจากสำเนาบัตรประชาชน)

ถ้าบังคับให้ผ่านระบบเหตุการณ์ จะต้องสร้างชนิดเหตุการณ์ใหม่ที่ไม่มี "คน" เป็นเจ้าของ
ซึ่งขัดกับรูปของตาราง `events` ที่ทุกแถวผูกกับคน และได้ความซับซ้อนมาโดยไม่มีคำถามไหนที่ตอบได้ดีขึ้น

## สิ่งที่ยังเก็บไว้แม้ไม่ผ่านเหตุการณ์

- ใครอัปโหลดและเมื่อไหร่ (`uploaded_by`, `created_at`) ทั้งรายการและทุกไฟล์
- การลบทำได้เฉพาะหัวหน้าทีม เพราะของกลางที่หายไปกระทบทุกคนและย้อนกลับไม่ได้

## ถ้าวันหนึ่งต้องทบทวน

ถ้าทีมเริ่มถามว่า "ตารางสอบฉบับก่อนแก้หน้าตาเป็นยังไง" แปลว่าต้องการประวัติเวอร์ชัน
ให้เพิ่มการเก็บเวอร์ชันของไฟล์ ไม่ใช่ย้ายไปอยู่ในระบบเหตุการณ์ของคน
