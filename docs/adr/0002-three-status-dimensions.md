# แยกสถานะเป็นสามเรื่องที่ไม่ขึ้นต่อกัน

คำว่า "สถานะ" ในงานของทีมหมายถึงสามเรื่องที่เปลี่ยนอิสระต่อกัน:
**สถานะการติดตาม** (ทีมเป็นเจ้าของ) **สถานะการเรียน** (สำนักทะเบียนเป็นเจ้าของ)
และ **สถานะการเงิน** (ฝ่ายการเงินเป็นเจ้าของ) เราเก็บเป็นสามช่องแยกกัน

## ทำไมถึงไม่ใช่ช่องเดียว

หลักฐานจากงานจริงสองเคสพิสูจน์ว่ายุบรวมไม่ได้:

- คนที่ **รักษาสภาพ** (ชำระไม่ครบ) ยังเข้าเรียนและเข้าสอบได้ตามปกติ
  — สถานะการเงินแย่ แต่สถานะการเรียนปกติ
- นักศึกษารายหนึ่งชำระค่าเทอมครบแล้วแต่ต้อง **ดรอป** เพราะผ่าตัดหัวใจ
  — สถานะการเงินปกติ แต่สถานะการเรียนหยุด

ถ้าใช้ช่องเดียว ทั้งสองเคสจะแสดงผลผิดทันที
