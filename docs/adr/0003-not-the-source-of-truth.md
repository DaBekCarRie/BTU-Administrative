# ระบบนี้ไม่ใช่แหล่งความจริงของข้อมูลที่มหาวิทยาลัยเป็นเจ้าของ

รหัสนักศึกษา เลขใบเสร็จ การลงทะเบียนสอบ และสถานะการเรียน
มีเจ้าของอยู่แล้วในระบบของมหาวิทยาลัย (สำนักทะเบียน ฝ่ายการเงิน และ
`btude.demyis.com/lms`) ระบบนี้เก็บเป็น**สำเนาที่ทีมบันทึกไว้** เท่านั้น
และไม่พยายามซิงก์อัตโนมัติ เพราะทีมไม่มีสิทธิ์เข้าถึงระบบเหล่านั้น

## ผลที่ตามมา

- ทุกหน้าจอที่แสดงสถานะการเรียนหรือสถานะการเงิน **ต้องแสดงวันที่ยืนยันล่าสุด
  ติดกับค่าเสมอ** เช่น `เรียนอยู่ · ยืนยันล่าสุด 3 เดือนที่แล้ว`
  การแสดงคำว่า "เรียนอยู่" เฉย ๆ ทำให้ทีมเชื่อว่าเป็นความจริงปัจจุบัน
  ทั้งที่อาจเก่าเป็นปี ซึ่งอันตรายกว่าไม่มีข้อมูลเลย
- รายชื่อศูนย์สอบพิเศษที่ทีมถือ อาจขัดกับการลงทะเบียนสอบจริงในระบบมหาวิทยาลัย
  ระบบเตือนให้ไปเช็คได้ แต่กระทบยอดให้เองไม่ได้
