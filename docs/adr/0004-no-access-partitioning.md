# เจ้าหน้าที่ทุกคนเห็นข้อมูลทั้งหมด ไม่กั้นตามเจ้าของเคส

ระบบนี้เก็บสำเนาบัตรประชาชนและที่อยู่ของคนหลักพันราย ซึ่งปกติจะเป็นเหตุผล
ให้กั้นข้อมูลตามเจ้าของเคส แต่เราเลือก **ไม่กั้น** — เจ้าหน้าที่ทุกคนเห็นและแก้
ข้อมูลผู้สนใจ กระดานงาน และเอกสารได้ทั้งหมด

## ทำไม (อย่า "แก้" ให้กั้นโดยไม่อ่านตรงนี้ก่อน)

ทีม 5 คนทำงานแทนกันตลอดเวลา — หลักฐานจากแชทงานจริง: คนหนึ่งพัก อีกคนรับเคสต่อ
ทันทีโดยไม่ส่งมอบอะไร ถ้ากั้นตามเจ้าของ งานจะค้างทุกครั้งที่มีคนลาหรือหยุด

ทีมยังตัดสินใจด้วยว่า **ไม่ทำเรื่องวัดผลรายบุคคล** ซึ่งเป็นเหตุผลหลักอีกข้อที่
คนมักกั้นข้อมูล พอไม่มีการวัดผล เหตุผลที่จะกั้นก็เหลือน้อยมาก

และวันนี้ทีมแชร์ทุกอย่างในกลุ่ม LINE อยู่แล้ว รวมถึงภาพบัตรประชาชน
ระบบที่กั้นแน่นกว่าของเดิมจะถูกเลี่ยงกลับไปใช้แชทแทน ซึ่งแย่กว่าเดิม

## สิ่งที่ยังต้องมีแม้ไม่กั้น

- การเปิดดูสำเนาบัตรประชาชนต้องกดปุ่มก่อน และ **บันทึก log ทุกครั้ง** ว่าใครเปิดของใคร
- RLS ยังเปิดทุกตาราง — policy คือ "ผู้ใช้ที่ล็อกอินแล้วเห็นได้" ไม่ใช่ "ปิด RLS"
  ความต่างอยู่ที่คนนอกยังเข้าไม่ได้เลย
- ถ้าทีมโตเกิน ~10 คน หรือเริ่มวัดผลรายบุคคล ให้กลับมาทบทวนข้อนี้
