# 03: โต๊ะตรวจเอกสารแบบรวมศูนย์และพรีวิวข้อมูลอ่อนไหว (Unified Document Review Desk)

**What to build:** ปรับปรุงหน้า `/documents` จากเดิมที่เป็นเพียงตารางนับคนเอกสารไม่ครบ ให้กลายเป็น "โต๊ะตรวจเอกสาร" (Document Review Desk)
แบบ Master-Detail Split View บนเดสก์ท็อป และ Card Review Sheet บนมือถือ
พร้อมแท็บสถานะ 4 หมวด, แผงตรวจเอกสาร 4 หมวดของผู้สมัครพร้อมจุดสถานะสี, ระบบเบลอเอกสารอ่อนไหวโดยค่าเริ่มต้นพร้อมปุ่มเปิดดูและบันทึก Audit Log,
และ Dropdown เหตุผลการส่งกลับแก้ไขมาตรฐาน 5 ข้อแทนการใช้ `window.prompt`

**Blocked by:** 01-responsive-shell-and-navigation.md

**Status:** done

- [x] สร้างโครงสร้าง Master-Detail Desk ในหน้า `/documents` (คอลัมน์ซ้าย: รายชื่อผู้ยื่นเอกสาร, คอลัมน์ขวา: พื้นที่ตรวจเอกสาร)
- [x] เพิ่มแท็บกรองสถานะด้านบน: "ทั้งหมด", "รอตรวจสอบ", "ผ่านแล้ว", "ต้องส่งใหม่" พร้อมแสดงจำนวน
- [x] คอลัมน์ซ้ายแสดงรายชื่อผู้สมัคร วันที่ยื่น หลักสูตร และชิปแสดงสถานะของเอกสารทั้ง 4 ชนิด (`รูปถ่าย`, `วุฒิ`, `บัตรปชช.`, `ทะเบียนบ้าน`) แยกสี

- [x] พื้นที่ตรงกลางแสดงตัวอย่างพรีวิวเอกสาร โดยเบลออัตโนมัติหากเป็นเอกสารอ่อนไหว (`สำเนาบัตรประชาชน`, `สำเนาทะเบียนบ้าน`)
