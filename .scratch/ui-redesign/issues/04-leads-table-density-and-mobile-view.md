# 04: ตารางผู้สนใจโหมดกะทัดรัด การจัดการหลายแถว และมุมมองการ์ดบนมือถือ (Leads Table & Mobile View)

**What to build:** ปรับปรุงหน้าตารางผู้สนใจ (`/leads`) ให้รองรับการเลือกรายการพร้อมกันหลายแถว (Bulk selection)
พร้อมแถบเครื่องมือรวมเมื่อมีการเลือก, ปรับปรุงคอลัมน์การกระทำปุ่ม "เปิดแฟ้ม" ให้ติดขอบขวา (Sticky right),
รองรับความหนาแน่นแบบกะทัดรัด (Compact density) พร้อมตัวเลข Tabular numerals,
และสำหรับหน้าจอมือถือ แปลงตารางเป็นรายการการ์ดแนวตั้งสัมผัสง่าย พร้อมชิปเลื่อนแนวนอนสำหรับกรองสถานะติดตาม

**Blocked by:** 01-responsive-shell-and-navigation.md

**Status:** done

- [x] เพิ่ม Checkbox ในหัวตารางและทุกแถวของตารางผู้สนใจ (`/leads`) เพื่อเลือกผู้สมัครทีละคน หรือเลือกทั้งหมด
- [x] แสดงแถบเครื่องมือลอย "เลือกไว้ X ราย" เมื่อมีการเลือกอย่างน้อย 1 แถว พร้อมปุ่ม "ส่งออกที่เลือก", "เปลี่ยนผู้ดูแล", และ "ยกเลิกการเลือก"
- [x] ทำคอลัมน์ "การกระทำ" (ปุ่มเปิดแฟ้ม) ให้เป็น Sticky right ติดขอบขวาของตารางเสมอเมื่อเลื่อนแนวนอน
- [x] รองรับการแสดงผลตารางที่มีระยะห่างแถวกะทัดรัด (Compact padding) และจัดตัวเลขเบอร์โทรและวันที่ด้วย IBM Plex Mono แบบ Tabular numbers

- [x] เพิ่มแถบชิปสถานะติดตามแบบเลื่อนแนวนอน (Horizontal Scroll Chips: ทั้งหมด, ใหม่, กำลังติดตาม, นัดโทรแล้ว, สนใจสมัคร, สมัครแล้ว, ไม่สนใจ, ติดต่อไม่ได้) เหนือรายการการ์ดบนมือถือ
