# 02: บันทึกผลโทรด่วนแบบแนบแถวและแถบสรุปงานคิวโทร (Fast Call Logger & Queue Density)

**What to build:** ปรับปรุงหน้าคิวโทร (`/queue`) ให้การบันทึกผลโทรทำได้อย่างรวดเร็วโดยไม่บดบังตาราง
บนเดสก์ท็อปเปิดเป็น Inline Popover ติดกับแถวนั้นในคอลัมน์ขวาสุด และบนมือถือเปิดเป็น Bottom Sheet พร้อมปุ่มสัมผัสขนาดใหญ่ 48px
รองรับปุ่มผลโทรด่วน 6 ข้อ, ปุ่มนัดวันถัดไปแบบลัด, อัปเดตแถวเป็นสีเขียวอ่อนทันที (Optimistic feedback),
เพิ่มแถบสรุปสถิติ Summary Strip (ค้างโทรวันนี้, โทรสำเร็จแล้ว, เลื่อนนัด), และปุ่มเปิด/ปิด Workboard Tiles

**Blocked by:** 01-responsive-shell-and-navigation.md

**Status:** done

- [x] แปลง Modal Dialog ของการบันทึกผลโทรในหน้า `/queue` เป็น Inline Popover บนเดสก์ท็อปที่แนบกับแถวผู้สมัคร
- [x] บนหน้าจอมือถือ แปลงการบันทึกผลโทรเป็น Bottom Sheet ที่เลื่อนขึ้นมาจากขอบล่าง พร้อมปุ่มผลโทรขนาด 48px แตะด้วยนิ้วเดียวได้สะดวก
- [x] ปุ่มผลโทรด่วน 6 ข้อ (ไม่รับสาย, คุยแล้วสนใจ, คุยแล้วไม่สนใจ, ขอคิดดูก่อน, นัดโทรใหม่, สมัครแล้ว) ที่ปรับสถานะติดตามตาม mapping
- [x] ปุ่มเลือกวันนัดถัดไปแบบลัด (พรุ่งนี้, 3 วัน, 1 สัปดาห์) และช่องปฏิทินที่ซ่อนอัตโนมัติเมื่อเลือกผลการโทรที่จบเคสแล้ว
- [x] เมื่อบันทึกสำเร็จ แถวในตารางเปลี่ยนพื้นหลังเป็นสีเขียวอ่อน `#F6FBF7` ปุ่มเปลี่ยนเป็น "บันทึกแล้ว · แก้ไข" และแสดง Toast แจ้งเตือน
- [x] เพิ่มแถบสรุป Summary Strip ด้านบน (ค้างโทรวันนี้, โทรสำเร็จแล้ว, เลื่อนนัด) ปรับยอดตามการบันทึกแบบเรียลไทม์
- [x] เพิ่มสวิตช์เปิด/ปิดกล่องสรุปงานค้าง Workboard Tiles เพื่อความยืดหยุ่นในการใช้พื้นที่หน้าจอ
- [x] ปรับปรุงการทดสอบ `e2e/queue.spec.ts` ให้ครอบคลุมทั้ง Inline Popover บนเดสก์ท็อป และ Bottom Sheet บนมือถือ
