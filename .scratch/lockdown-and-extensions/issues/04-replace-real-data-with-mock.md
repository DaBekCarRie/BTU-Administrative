# 04: แทนข้อมูลจริงด้วยข้อมูลสมมติ

**What to build:** ถอดข้อมูลส่วนบุคคลจริงออกจากระบบทั้งหมดแล้วแทนด้วยข้อมูลสมมติ
โดยยังนำข้อมูลจริงกลับเข้ามาได้เมื่อพร้อมใช้งานจริง

**⚠️ ใบนี้ลบข้อมูลจริง** ก่อนเริ่มต้องรายงานจำนวนแถวที่จะกระทบให้คนอนุมัติเห็นก่อน
และต้องยืนยันว่าไฟล์นำเข้าต้นฉบับถูกสำรองไว้แล้ว เพราะหลังล้างฐานข้อมูล
ไฟล์นั้นจะเป็นสำเนาเดียวของข้อมูลจริงที่เหลืออยู่

ต้องล้างแล้วนำเข้าใหม่ **ไม่ใช่เขียนทับ payload ของเหตุการณ์เดิม** เพราะ ADR-0001
และ `CONTEXT.md` กำหนดว่าเหตุการณ์บันทึกแล้วไม่ลบไม่แก้ การแทนข้อมูลจึงต้องเป็น
ชุดเหตุการณ์ใหม่ทั้งชุด และการแก้แค่ตารางสถานะปัจจุบันจะถูกลบล้างทันทีที่มีคนสั่งสร้างใหม่จากเหตุการณ์

- [ ] ลบไฟล์ทั้งหมดในที่เก็บเอกสารรายคน — มีสำเนาบัตรประชาชนจริงอยู่ในนั้น
      ถ้าไม่ลบ การถอดข้อมูลจริงออกจะทำแค่ครึ่งเดียว

      ตอนนำเข้า · เทสต์ของตารางนั้น · เทสต์กระดานงานค้างที่ยืนยันว่าชื่อจริงไม่โผล่ ·
      เอกสารออกแบบที่อ้างชื่อคนจริง
- [ ] ตรวจคลังคำตอบทีละรายการ แทนชื่อคนจริงถ้าพบ

- [ ] สั่งสร้างสถานะปัจจุบันใหม่จากเหตุการณ์แล้วตรงทุกแถว
- [ ] ไม่มีรายการที่วันติดต่อเข้ามาอยู่ในอนาคตเหลืออยู่
