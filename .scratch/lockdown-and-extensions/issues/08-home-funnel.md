# 08: หน้าแรก — กรวยเดือนนี้เทียบเดือนที่แล้ว

**What to build:** หัวหน้าทีมเปิดระบบมาแล้วตอบได้ทันทีว่า "จากคนที่ทักเข้ามาเดือนนี้
ไปถึงยื่นสมัครจริงกี่คน" และ "เทียบเดือนที่แล้วแล้วเป็นยังไง" โดยที่เจ้าหน้าที่ยังเห็น
คิวโทรวันนี้ในหน้าเดียวกัน ไม่ถูกดันให้ลึกลงไปอีกคลิก

**ตัวเลขล้วน ไม่มีกราฟ** — เหตุผลเดิมของ spec รอบแรกยังใช้อยู่ คือรอให้ทีมใช้จริงก่อน
จึงรู้ว่าอยากเห็นกราฟอะไร และ**ห้ามแยกตัวเลขเป็นรายบุคคลของเจ้าหน้าที่** (ADR-0004)

ข้อควรรู้: วันนี้ยังไม่มีการสมัครจริงในระบบเลย ช่วงปลายกรวยจะเป็นศูนย์
หน้าจอต้องไม่ดูเหมือนพัง

**Blocked by:** 02

**Status:** claimed

- [ ] หน้าแรกเลิกเด้งไปหน้าคิวโทร กลายเป็นหน้าจริงที่มีเนื้อหา
- [ ] กรวยห้าขั้น: ติดต่อเข้ามา → สนใจสมัคร → ยื่นสมัคร → ชำระแล้ว → ได้รหัสนักศึกษา
- [ ] **นับคนไม่ใช่นับใบสมัคร** คนที่สมัครสองรอบไม่ถูกนับสองครั้ง
- [ ] แต่ละขั้นแสดงตัวเลขเดือนนี้ เทียบเดือนที่แล้ว พร้อมส่วนต่าง
- [ ] การนับทำในฐานข้อมูลเพื่อไม่ให้ถูกตัดเงียบ ๆ เมื่อข้อมูลโต
      (ตามแบบที่กระดานงานค้างทำอยู่แล้ว)
- [ ] ขอบเขตเดือนคำนวณเป็นฟังก์ชันบริสุทธิ์ตามเวลาไทย แล้วส่งเข้าฐานข้อมูลเป็นพารามิเตอร์
      มีเทสต์ที่ตรึงเวลาระบบ ครอบช่วงหลังเที่ยงคืนถึงเจ็ดโมงเช้าซึ่งเคยทำให้วันที่เพี้ยน
- [ ] รายการที่วันติดต่อเข้ามาอยู่ในอนาคตไม่ถูกนับเข้าช่วงเวลาใด
- [ ] ขั้นที่ยังไม่มีข้อมูลแสดงศูนย์พร้อมคำอธิบายสั้น ๆ ไม่ใช่ช่องว่าง
- [ ] **คิวโทรวันนี้อยู่ในหน้าแรกด้วย** และคิวโทรยังมีเมนูของตัวเองเหมือนเดิม
- [ ] กระดานงานค้างที่มีอยู่แล้วยังอยู่ ไม่เสียของที่เพิ่งทำเสร็จ
- [ ] เทสต์ยืนยันว่าหน้าแรกไม่มีกราฟหรือแผนภูมิ
- [ ] เทสต์ยืนยันว่าชื่อเจ้าหน้าที่ไม่โผล่บนตัวเลขภาพรวม
- [ ] ใช้งานบนมือถือได้
