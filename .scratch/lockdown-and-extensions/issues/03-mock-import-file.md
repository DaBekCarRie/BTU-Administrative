# 03: เตรียมข้อมูลสมมติ — ด่านวันที่ และไฟล์นำเข้า

**What to build:** ด่านปฏิเสธวันติดต่อเข้ามาที่เป็นไปไม่ได้ และไฟล์นำเข้าฉบับสมมติที่พร้อมใช้
แทนไฟล์จริง ใบนี้**ยังไม่แตะฐานข้อมูล** จึงตรวจได้โดยไม่เสี่ยงอะไร

ความรุงรังของข้อมูลจริงคือสิ่งที่กฎล้างข้อมูลถูกเขียนมาแก้ ถ้าไฟล์สมมติสะอาดเกินไป
บั๊กที่เคยแก้จะกลับมาโดยไม่มีเทสต์ไหนจับได้ — ข้อนี้สำคัญกว่าความสวยของข้อมูล

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] วันติดต่อเข้ามาที่เลยวันนี้เกิน 30 วันถือว่าพิมพ์ผิด ทิ้งค่าวันที่นั้น (ไม่ทิ้งทั้งแถว)
      แก้ที่ฟังก์ชันบริสุทธิ์ซึ่งมีด่าน ±400 วันอยู่แล้ว เพื่อให้ครอบการนำเข้าครั้งต่อไปด้วย
- [ ] ด่านนี้ใช้กับวันติดต่อเข้ามาเท่านั้น **ไม่ใช้กับวันนัดโทร** ซึ่งต้องเป็นอนาคตโดยธรรมชาติ
      — มีเทสต์ตรึงทั้งสองกรณี
- [ ] การนำเข้ารายงานจำนวนวันที่ที่ถูกตัดออกเมื่อจบ ไม่ทิ้งเงียบ ๆ
- [ ] สคริปต์สร้างไฟล์นำเข้าสมมติ แทนที่เฉพาะช่อง**ชื่อ · เบอร์โทร · ชื่อผู้ดูแล**
      คงคอลัมน์อื่น จำนวนแถว และลำดับแถวไว้ทั้งหมด
- [ ] เบอร์โทรที่ซ้ำกันในไฟล์จริง ต้องยังซ้ำกันเป็นคู่เดิมในไฟล์สมมติ
- [ ] ชื่อที่มีวรรณยุกต์ซ้ำ ต้องยังมีวรรณยุกต์ซ้ำ
- [ ] ชื่อผู้ดูแลที่เขียนหลายแบบ ต้องยังเขียนหลายแบบ
- [ ] คอลัมน์คณะ สาขา วุฒิ และช่องติดตามที่ปนสถานะกับวันที่ **ไม่ถูกแตะเลย**
- [ ] ไฟล์นำเข้าสมมติถูกเก็บเข้าที่เก็บโค้ด เพื่อให้ตั้งต้นระบบใหม่ได้โดยไม่พึ่งไฟล์ในเครื่องใคร
- [ ] ยืนยันว่าไม่มีชื่อ เบอร์ หรือข้อมูลส่วนบุคคลจริงหลงอยู่ในไฟล์ที่จะเข้า git
