# 02: ปิดสิทธิ์เฉพาะเจ้าหน้าที่

**What to build:** คนที่ไม่ใช่เจ้าหน้าที่ที่ยังใช้งานอยู่ อ่านข้อมูลของระบบไม่ได้เลย
ไม่ว่าจะเข้าทางหน้าเว็บหรือถือ token ยิงเข้า API ของฐานข้อมูลตรง ๆ

**เร่งด่วนที่สุดในรอบนี้** — ตรวจแล้วว่าวันนี้ `disable_signup` เป็นเท็จและ Google เปิดใช้อยู่
แปลว่าใครก็ได้บนอินเทอร์เน็ตสมัครแล้วอ่านข้อมูลคนกว่าสามพันรายได้ทันที
ทดสอบบนฐานข้อมูลจริงแล้วว่าผู้ที่ล็อกอินแต่ไม่มีแถวเจ้าหน้าที่อ่านได้: คน 3,434 ·
เหตุการณ์ 6,497 · เอกสาร 52 · การชำระเงิน 27

นี่คือการ**รักษา**เจตนาของ ADR-0004 ไม่ใช่ขัด — ADR นั้นห้ามกั้นข้อมูล*ระหว่างเจ้าหน้าที่*
และเขียนไว้เองว่า "ความต่างอยู่ที่คนนอกยังเข้าไม่ได้เลย" ซึ่งปุ่มลงชื่อเข้าใช้ด้วย Google
ทำให้ไม่จริง เจ้าหน้าที่ทุกคนยังเห็นและแก้ข้อมูลได้ทั้งหมดเหมือนเดิม
