# 05: จัดบัญชีและปิดการสมัครใหม่

**What to build:** เหลือบัญชีเท่าที่จำเป็นในระบบ หัวหน้าทีมล็อกอินด้วย Google ของตัวเองได้
และไม่มีใครสมัครบัญชีใหม่เข้ามาได้อีก

ผลพลอยได้ที่สำคัญ: การรวมรายการที่เป็นคนเดียวกันต้องการสิทธิ์หัวหน้าทีม ซึ่งวันนี้
มีแต่บัญชีทดสอบเท่านั้นที่ถืออยู่ ทำให้ฟีเจอร์นั้นทีมจริงใช้ไม่ได้เลยตั้งแต่ทำเสร็จ
ใบนี้ทำให้มันใช้งานได้เป็นครั้งแรก

**Blocked by:** 02, 04

**Status:** ready-for-human — ส่วนของ agent เสร็จแล้ว เหลือสองข้อที่ต้องใช้บัญชี Google และ Dashboard ของหัวหน้าทีม

- [x] ผูกบัญชี Google ของหัวหน้าทีมเข้ากับแถวเจ้าหน้าที่ `role` หัวหน้าทีม
- [ ] ล็อกอินด้วยปุ่มลงชื่อเข้าใช้ด้วย Google แล้วเข้าใช้งานได้จริง ยืนยันด้วยการลองจริง
      **หัวหน้าทีมต้องกดเอง** — agent กรอกรหัสผ่าน Google แทนไม่ได้
- [x] ลบบัญชีโดเมนสมมติที่ไม่ได้ใช้ทิ้ง เหลือเฉพาะบัญชีหัวหน้าทีมและบัญชีทดสอบสามบัญชี
- [x] แถวเจ้าหน้าที่ที่ไม่ผูกบัญชีเข้าระบบ ยังเป็นเจ้าของเคสได้เหมือนเดิม
- [x] รวมรายการที่เป็นคนเดียวกันได้จริงด้วยบัญชีหัวหน้าทีม
- [x] เจ้าหน้าที่ที่ไม่ใช่หัวหน้าทีมรวมรายการไม่ได้ พร้อมข้อความที่อ่านรู้เรื่อง
- [x] คนที่ล็อกอินได้แต่ยังไม่ถูกผูกเป็นเจ้าหน้าที่ เห็นหน้าบอกว่ายังไม่มีสิทธิ์
      ไม่ใช่หน้าพังหรือหน้าว่าง
- [x] บันทึกขั้นตอนปิดการสมัครใหม่บน Dashboard ไว้ในเอกสารความคืบหน้า
      พร้อมวิธีเปิดชั่วคราวเวลาต้องเพิ่มเจ้าหน้าที่
- [x] แก้ข้อที่เอกสารความคืบหน้าติ๊กว่าสร้างบัญชีเจ้าหน้าที่ครบแล้ว ให้ตรงความจริง

## ผลการทำ (13 ก.ย. 2569)

- `npm run accounts:lead -- --email "<อีเมล>" [--confirm]` (สคริปต์ใหม่ `scripts/setup-lead-account.mts`)
  สร้างบัญชีหัวหน้าทีมด้วยอีเมล Google ที่ยืนยันแล้ว **ไม่ตั้งรหัสผ่าน** แล้วผูกแถวเจ้าหน้าที่
  `display_name` "หัวหน้าทีม" role หัวหน้าทีม · กด Google ครั้งแรก Supabase ผูก identity เข้าบัญชีนี้เอง
  เพราะอีเมลตรงและยืนยันแล้ว (ไม่ต้องเปิดการสมัครใหม่) · อีเมลส่งเป็น argument ไม่เขียนลงโค้ด
- ลบบัญชี `@btu-admin.dev` ที่ไม่ใช่บัญชีทดสอบ **5 บัญชี** · เหลือ auth 4 บัญชี: หัวหน้าทีม + ทดสอบ 3
- แถวเจ้าหน้าที่ 5 แถวหลุดการผูก (FK set null) แต่ยังเป็นเจ้าของเคสครบ 2,095 ราย ·
  เทสต์ `e2e/accounts.spec.ts`: กรองรายชื่อตามเจ้าหน้าที่ที่ไม่มีบัญชีได้
- สิทธิ์รวมรายการ: หัวหน้าทีมรวมได้ (เทสต์เดิม `duplicate.spec.ts`) · เจ้าหน้าที่กดแล้วเห็น
  "รวมข้อมูลได้เฉพาะหัวหน้าทีม" และไม่มีรายการหาย (เทสต์ใหม่ด้วยบัญชีเจ้าหน้าที่จริง)
- คนนอกทีมเห็นหน้าบอกว่าไม่มีสิทธิ์ — ทำในใบ 01 (`route-handlers.spec.ts`)
- ขั้นตอนปิด/เปิดการสมัครใหม่ และแก้ข้อ "สร้างบัญชีครบ 5 คน" อยู่ใน `docs/PROGRESS.md`

**เหลือให้หัวหน้าทีมทำเอง**
1. เปิดแอป กด "ลงชื่อเข้าใช้ด้วย Google" ด้วยบัญชีที่ตั้งไว้ แล้วลองรวมรายการซ้ำหนึ่งครั้ง
2. ปิดการสมัครใหม่บน Dashboard ตามขั้นตอนใน `docs/PROGRESS.md`
