# 06: เอกสารอ้างอิง — เก็บและเปิดดู

**What to build:** ที่เก็บของกลางที่ทีมเปิดดูเพื่ออ้างอิง — ตารางสอบแต่ละปี ปฏิทินการศึกษา
แบบฟอร์ม ประกาศ และรูปประชาสัมพันธ์ ซึ่งวันนี้อยู่ในแชท LINE และไดรฟ์ส่วนตัว หาไม่เจอเวลาต้องใช้

**เอกสารอ้างอิง** เป็นคำใหม่ในคำศัพท์ของโปรเจกต์ ต่างจาก **เอกสาร** เฉย ๆ ซึ่งหมายถึง
เอกสารประจำตัวของรายคนที่ต้องตรวจผ่าน/ไม่ผ่าน เอกสารอ้างอิงไม่ผูกกับคนและไม่มีการตรวจ

อยู่นอกระบบเหตุการณ์โดยตั้งใจ — ADR-0001 บังคับว่าการเขียนข้อมูล*คน*ต้องผ่านเหตุการณ์
เอกสารอ้างอิงไม่ผูกกับคนจึงไม่เข้าข่าย

**Blocked by:** 02

**Status:** claimed

- [ ] เพิ่มคำ **เอกสารอ้างอิง** ใน `CONTEXT.md` พร้อมนิยามและคำที่ต้องเลี่ยง
      และเติมให้ **เอกสาร** ชัดว่าหมายถึงของรายคนเท่านั้น
- [ ] เมนูใหม่แยกจากเมนูเอกสารรายคน ไม่ใช่แท็บที่ห้าในหน้าเดิม
- [ ] เพิ่มรายการเอกสารอ้างอิงได้ พร้อมหมวด ชื่อเรื่อง และปีการศึกษา
- [ ] หมวดเป็นค่าคงที่ให้เลือก ไม่ใช่ช่องพิมพ์อิสระ (`CLAUDE.md` กฎข้อ 4):
      ตารางสอบ · ปฏิทินการศึกษา · แบบฟอร์ม · ประกาศ · สื่อประชาสัมพันธ์ · อื่นๆ
- [ ] ปีการศึกษาเว้นว่างได้ เพราะรูปประชาสัมพันธ์ไม่ผูกกับปี แต่ตารางสอบผูก
- [ ] ปีการศึกษาเก็บเป็น พ.ศ. แบบเดียวกับปีการศึกษาของการสมัครที่มีอยู่แล้ว
- [ ] แนบไฟล์หลายไฟล์ในรายการเดียวได้ เพราะตารางสอบมักมีหลายหน้าหรือหลายภาค
- [ ] ไฟล์เก็บในที่เก็บแยกถังจากเอกสารรายคน เพื่อให้เขียนสิทธิ์ต่างกันได้
      และกันอุบัติเหตุที่สคริปต์ล้างไฟล์รายคนไปโดนเอกสารอ้างอิง
- [ ] เปิดดูไฟล์ผ่านลิงก์อายุสั้นที่สร้างจากฝั่งเซิร์ฟเวอร์ ถังเป็นแบบปิดทั้งหมด
- [ ] รูปถูกย่อขนาดอัตโนมัติก่อนอัปโหลดด้วยกลไกเดียวกับที่เอกสารรายคนใช้
- [ ] เห็นว่าใครอัปโหลดและเมื่อไหร่
- [ ] ไม่มีสถานะผ่าน/ไม่ผ่าน และไม่เขียนบันทึกการเปิดดู เพราะไม่ใช่ข้อมูลส่วนบุคคล
- [ ] เจ้าหน้าที่ทุกคนอ่านและอัปโหลดและแก้ได้
- [ ] เขียน ADR "เอกสารอ้างอิงอยู่นอกระบบเหตุการณ์" อธิบายว่าทำไมเขียนตารางตรงได้
- [ ] ใช้งานบนมือถือได้เหมือนหน้าจออื่นที่ปรับไปแล้ว
