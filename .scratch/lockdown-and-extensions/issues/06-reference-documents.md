# 06: เอกสารอ้างอิง — เก็บและเปิดดู

**What to build:** ที่เก็บของกลางที่ทีมเปิดดูเพื่ออ้างอิง — ตารางสอบแต่ละปี ปฏิทินการศึกษา
แบบฟอร์ม ประกาศ และรูปประชาสัมพันธ์ ซึ่งวันนี้อยู่ในแชท LINE และไดรฟ์ส่วนตัว หาไม่เจอเวลาต้องใช้

**เอกสารอ้างอิง** เป็นคำใหม่ในคำศัพท์ของโปรเจกต์ ต่างจาก **เอกสาร** เฉย ๆ ซึ่งหมายถึง
เอกสารประจำตัวของรายคนที่ต้องตรวจผ่าน/ไม่ผ่าน เอกสารอ้างอิงไม่ผูกกับคนและไม่มีการตรวจ

อยู่นอกระบบเหตุการณ์โดยตั้งใจ — ADR-0001 บังคับว่าการเขียนข้อมูล*คน*ต้องผ่านเหตุการณ์

## ตัดสินใจระหว่างทาง

- **รับเฉพาะรูปและ PDF** ตามถังเอกสารประจำตัว — แบบฟอร์มที่เป็นไฟล์ Word/Excel ต้องแปลงเป็น PDF ก่อน
  ถ้าทีมต้องการแนบ Word ตรง ๆ แก้ `allowed_mime_types` ของ bucket กับ `REFERENCE_MIME_EXTENSION` คู่กัน
- ปีการศึกษาให้เลือกปีหน้าย้อนไปห้าปี + "ไม่ผูกกับปี" — ปีเก่ากว่านั้นที่มีอยู่แล้วยังแสดงให้เลือกตอนแก้
- เพิ่มรายการแล้วถ้าบางไฟล์อัปโหลดพัง รายการยังอยู่และแนบเพิ่มทีหลังได้ ไม่ต้องกรอกใหม่
