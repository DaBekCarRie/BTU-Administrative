# 05: บันทึกผลการโทรและไทม์ไลน์

**What to build:** เจ้าหน้าที่วางสายแล้วบันทึกผลจากมือถือจบได้ในไม่กี่แตะ นัดโทรครั้งถัดไปแบบลัด
และเปิดดูประวัติการติดตามทั้งหมดของคนหนึ่งได้ไม่จำกัดจำนวนครั้ง

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] บันทึกผลโทรจบได้ใน 3 แตะบนมือถือ ปุ่มสำคัญอยู่ครึ่งล่างของจอ
- [ ] ผลลัพธ์ให้เลือก: ไม่รับสาย · คุยแล้วสนใจ · คุยแล้วไม่สนใจ · ขอคิดดูก่อน · นัดโทรใหม่ · สมัครแล้ว
- [ ] นัดครั้งถัดไปเลือกแบบลัดได้ พรุ่งนี้ / 3 วัน / 1 สัปดาห์ / เลือกวันเอง
- [ ] **ระบุวันที่ที่โทรจริงย้อนหลังได้** และไทม์ไลน์เรียงตามเวลาที่เกิดจริง ไม่ใช่เวลาที่บันทึก
- [ ] ปิดเคสพร้อมเหตุผลแล้วคนนั้นไม่โผล่ในคิวอีก
- [ ] ไทม์ไลน์แสดงประวัติเรียงใหม่ไปเก่า ไม่จำกัดจำนวนครั้ง
- [ ] สถานะการติดตามและวันนัดครั้งถัดไปคำนวณจากเหตุการณ์ ไม่ใช่แก้ค่าตรง ๆ
- [ ] Playwright smoke "บันทึกผลโทร" ผ่าน
