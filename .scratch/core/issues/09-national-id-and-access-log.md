# 09: เลขบัตรประชาชนและ log การเปิดดู

**What to build:** ข้อมูลที่อ่อนไหวที่สุดในระบบถูกเก็บแบบเข้ารหัส และทุกการเปิดดูมีร่องรอย
เจ้าหน้าที่ทุกคนยังเปิดดูได้ (ไม่กั้นตามเจ้าของเคส ตาม ADR-0004) แต่ต้องกดปุ่มและถูกบันทึก

**Blocked by:** 08

**Status:** ready-for-agent

- [ ] เลขบัตรประชาชนเก็บเข้ารหัส คีย์อยู่ใน Supabase Vault — **ไม่อยู่ใน env และไม่ hardcode**
- [ ] หน้าจอปกติแสดงเพียง 4 ตัวท้าย
- [ ] ถอดรหัสได้ทางเดียวคือผ่านฟังก์ชันที่เช็คสิทธิ์และเขียน log — ไม่มีเส้นทางอื่น
- [ ] สำเนาบัตรประชาชนแสดงเป็นภาพเบลอจนกดปุ่มเปิด พร้อมข้อความว่าการเปิดจะถูกบันทึก
- [ ] หัวหน้าทีมเปิดหน้าดู log ได้ว่าใครเปิดของใครเมื่อไหร่
- [ ] เทสต์ยืนยันว่าเปิดดู 1 ครั้ง เกิด log 1 แถว
