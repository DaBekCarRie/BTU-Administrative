# 14: กระดานงานค้างและตัวเลขรวม

**What to build:** หน้าแรกที่ตอบว่า "ตอนนี้ต้องทำอะไร" ไม่ใช่ตารางข้อมูลเปล่า ๆ
พร้อมแถบตัวเลขรวมเล็ก ๆ ให้เห็นภาพรวม

**Blocked by:** 06, 08, 11

**Status:** ready-for-agent

- [ ] แสดงงานค้างแยกประเภท อย่างน้อย: คิวโทรวันนี้ · ผู้สนใจที่ไม่มีใครแตะเกิน 7 วัน ·
      ผู้เรียนที่ชำระแล้วแต่ยังไม่ได้รหัสนักศึกษาเกิน 3 วัน · เอกสารไม่ครบ
- [ ] กดที่ตัวเลขแต่ละอันแล้วไปหน้ารายชื่อที่กรองไว้แล้ว
- [ ] แถบตัวเลขรวมด้านบนแสดง สมัครเดือนนี้ · เรียนอยู่ · ดรอป
- [ ] **ไม่มีตัวเลขแยกรายบุคคลของเจ้าหน้าที่ที่ไหนเลยบนหน้านี้** — ทีมตัดสินใจไม่ทำเรื่องวัดผลคน
- [ ] เกณฑ์จำนวนวัน (7 วัน / 3 วัน) แก้ได้จากที่เดียว ไม่กระจายอยู่หลายที่ในโค้ด
- [ ] ไม่มีกราฟหรือแผนภูมิใด ๆ
