# 13: ศูนย์สอบพิเศษ

**What to build:** แทนรายชื่อศูนย์สอบพิเศษที่ทุกวันนี้ถูกพิมพ์ใหม่ทั้งก้อนในแชท
(3 ครั้งใน 4 วัน) ด้วยรายการที่แก้ทีละคนแล้วกดออกรายชื่อส่งต่อได้

**Blocked by:** 10

**Status:** done

- [x] บันทึกคำขอศูนย์สอบพิเศษ ระบุคน ปีการศึกษา และศูนย์
- [x] ถอนคำขอได้ โดยยังเห็นในไทม์ไลน์ว่าเคยขอและถอนเมื่อไหร่
- [x] หน้าสรุปแสดงรายชื่อแยกตามศูนย์ พร้อมระดับและหลักสูตรของแต่ละคน
- [x] คัดลอกหรือส่งออกรายชื่อแยกตามศูนย์ได้ในคลิกเดียว
- [x] **มีข้อความเตือนว่ารายชื่อนี้ไม่ซิงก์กับระบบลงทะเบียนสอบของมหาวิทยาลัย ต้องไปเช็กเอง**
      (ADR-0003 — ทีมไม่ได้เป็นเจ้าของข้อมูลการลงทะเบียนสอบ)

## ผลการตรวจ

- ขอศูนย์สอบแล้วขึ้นในหน้าสรุป แยกตามศูนย์
- ถอนคำขอแล้วหายจากหน้าสรุป แต่ยังเห็นในไทม์ไลน์ว่าเคยขอและถอนเมื่อไหร่
- คัดลอกรายชื่อแยกตามศูนย์ได้ในคลิกเดียว (เทสต์อ่าน clipboard จริง)
- หน้าสรุปขึ้นคำเตือนว่าไม่ซิงก์กับระบบมหาวิทยาลัย
- e2e 51/51 · typecheck · lint · build ผ่าน · `db:verify` ตรงทุกแถว

## การตัดสินใจ

- **ถอนคำขอคือเปลี่ยนสถานะเป็น "ถอนแล้ว" ไม่ใช่ลบทิ้ง** เพราะในแชทงานจริง
  มีเคสนักศึกษาขอแล้วเปลี่ยนใจ ทีมต้องรู้ว่าเคยขอไว้ตอนไหน
- **ศูนย์สอบเป็นช่องพิมพ์พร้อมรายการแนะนำ ไม่ใช่ dropdown ปิด**
  ต่างจากคณะ/สาขาที่ต้องเป็น FK — เพราะศูนย์สอบเปลี่ยนทุกปีตามที่มหาวิทยาลัยเปิด
  และไม่ได้ใช้ทำรายงานที่ต้องนับ
- **ปุ่มคัดลอกจัดรูปแบบเป็นรายการมีเลขลำดับ** ให้ตรงกับที่ทีมพิมพ์ส่งในแชทอยู่แล้ว
  จะได้วางลง LINE แล้วใช้ได้เลย
- คำเตือน "ไม่ซิงก์กับระบบมหาวิทยาลัย" อยู่ทั้งหน้าสรุปและในแผงของแต่ละคน
  ตาม ADR-0003 — ทีมไม่ได้เป็นเจ้าของข้อมูลการลงทะเบียนสอบ

## ปรับชุดเทสต์

ชื่อทดสอบเคยใช้ `<คำ> ${Date.now()}` ซึ่งชนกันได้เมื่อ worker เริ่มพร้อมกัน
เช่น `สอบ <ts>` เป็นสตริงย่อยของ `ถอนสอบ <ts>` ทำให้ locator เจอสองรายการ
เปลี่ยนมาใช้ `uniqueName()` ที่ต่อ token สุ่มแทน
