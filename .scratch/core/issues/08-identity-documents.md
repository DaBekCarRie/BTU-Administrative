## ผลการตรวจ

- อัปโหลดแล้วเช็กลิสต์เปลี่ยน · ตรวจผ่านแล้วนับเพิ่ม
- **ส่งแล้วแต่ยังไม่ตรวจ ไม่นับว่าครบ** — มีเทสต์ยืนยัน
- ไม่ผ่านต้องบอกเหตุผล และเหตุผลแสดงให้คนรับงานต่อเห็น
- สำเนาบัตรประชาชนขึ้นข้อความว่าการเปิดดูจะถูกบันทึก ส่วนรูปถ่ายไม่ขึ้น
- หน้า /documents แสดงคนที่เอกสารยังไม่ครบ
- e2e 35/35 (รันซ้ำสองรอบผ่านทั้งคู่) · typecheck · lint · build ผ่าน

## บั๊กจริงที่เจอ — Storage ไม่รับอักษรไทยใน path

ตั้งชื่อไฟล์เป็น `<personId>/รูปถ่าย-<timestamp>.png` แล้ว Supabase Storage ตอบ 400
โดยไม่มีข้อความบอกสาเหตุที่หน้าจอ ผู้ใช้เห็นแค่ปุ่มกลับไปเป็น "ยังไม่ส่ง" เงียบ ๆ

แก้ด้วยตาราง `DOC_TYPE_SLUG` ที่ map ชื่อไทยเป็น slug อังกฤษสำหรับตั้งชื่อไฟล์
ส่วนที่แสดงบนหน้าจอยังเป็นภาษาไทยตามเดิม และเพิ่ม `console.error` ตอนอัปโหลดพลาด

## การตัดสินใจ

- **นับ "ครบ" จากจำนวนที่ตรวจผ่าน ไม่ใช่จำนวนที่อัปโหลด** — ไฟล์เบลอที่อ่านไม่ออก
  ไม่ควรทำให้เช็กลิสต์ขึ้นเขียว
- บีบอัดรูปเหลือประมาณ 300 KB ก่อนอัปโหลด (`browser-image-compression`)
  และบอกผู้ใช้ว่าย่อลงกี่เปอร์เซ็นต์ เพื่อให้เห็นว่าระบบทำอะไรให้
- ค่าคงที่ที่ client ใช้ร่วม (slug, ประเภทอ่อนไหว) แยกไว้ที่ `lib/documents-shared.ts`
  เพราะไฟล์ใน `lib/data/` มี `server-only` ซึ่ง client component import ไม่ได้
- ลิงก์เปิดเอกสารอายุ 60 วินาที สร้างจากฝั่งเซิร์ฟเวอร์เท่านั้น
