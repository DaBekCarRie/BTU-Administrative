# 04: ค้นหา กรอง และส่งออก Excel

**What to build:** หน้ารายชื่อใช้งานได้จริงกับข้อมูลหลักพันราย — ค้นเจอแม้พิมพ์ไม่ครบ
กรองได้หลายเงื่อนไขพร้อมกัน และส่งออกผลลัพธ์ที่กรองแล้วเป็นไฟล์

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] ค้นด้วยชื่อไทย ชื่อ Facebook ภาษาอังกฤษ หรือเบอร์โทร ได้ผลแม้พิมพ์ไม่ครบ
- [ ] ใช้ trigram index — **ไม่ใช่ full-text search** เพราะ Postgres ตัดคำไทยไม่ได้
- [ ] เทสต์ที่พิสูจน์ข้อบน: ค้น "ศิริ" แล้วต้องเจอ "ศิริพร"
- [ ] กรองตามสถานะการติดตาม คณะ ภาค และผู้ดูแล พร้อมกันได้ ทุกอันเป็น dropdown
- [ ] กรอง เรียง และแบ่งหน้าทำที่ฝั่งเซิร์ฟเวอร์ ไม่ดึงทุกแถวมากรองในเบราว์เซอร์
- [ ] แสดงจำนวนผลลัพธ์ทั้งหมดหลังกรอง
- [ ] **เห็นอย่างน้อย 15 แถวต่อจอบนเดสก์ท็อป** — ต่ำกว่านี้ทีมจะรู้สึกช้ากว่าชีทเดิม
- [ ] ปุ่มส่งออก Excel ส่งออกเฉพาะผลลัพธ์ที่กรองอยู่ ไม่ใช่ทั้งตาราง
