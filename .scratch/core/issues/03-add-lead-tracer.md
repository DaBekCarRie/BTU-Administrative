# 03: เพิ่มผู้สนใจแล้วเห็นในรายชื่อ

**What to build:** tracer bullet ของทั้งระบบ — เจ้าหน้าที่กรอกฟอร์มเพิ่ม `ผู้สนใจ` หนึ่งคน
แล้วชื่อโผล่ในรายชื่อทันที ใบนี้วางรากทั้งหมดที่ใบอื่นจะพึ่ง: ตาราง `คน` กับ `เหตุการณ์`
โมดูลโดเมนที่คำนวณ `สถานะปัจจุบัน` และแบบแผนการทดสอบ

**หน้าตาเรียบได้ ไม่ต้องสวย** ความสวยและการค้นหาเป็นเรื่องของใบ 04

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] ตาราง `คน` และ `เหตุการณ์` เปิด RLS ทั้งคู่
- [ ] `เหตุการณ์` รองรับครบ 15 ชนิดตาม spec รวม `แก้ไขข้อมูล` และเก็บ
      เวลาที่เกิดจริง · เวลาที่บันทึก · ผู้บันทึก แยกกัน
- [ ] มีฟังก์ชันบริสุทธิ์ที่รับสถานะเดิมกับเหตุการณ์แล้วคืนสถานะใหม่ **ทดสอบได้โดยไม่ต้องมีฐานข้อมูล**
- [ ] การเขียนทุกครั้งผ่านฟังก์ชันบันทึกเดียว ที่เขียน `เหตุการณ์` และอัปเดต `คน` ในทรานแซกชันเดียว
- [ ] **มีคำสั่งสร้าง `คน` ใหม่จาก `เหตุการณ์` ทั้งหมด และให้ผลเท่าเดิมทุกแถว**
- [ ] ฟอร์มเพิ่มผู้สนใจ — คณะ สาขา ภาค วุฒิ ผู้ดูแล เป็น dropdown ทั้งหมด ไม่มีช่องพิมพ์อิสระ
- [ ] เบอร์โทรถูกจัดรูปแบบให้เหมือนกันก่อนบันทึกเสมอ
- [ ] แก้ข้อมูลติดต่อแล้วเกิดเหตุการณ์ `แก้ไขข้อมูล` — **ห้าม `UPDATE` ตาราง `คน` ตรง ๆ**
- [ ] หน้ารายชื่อแสดงคนที่เพิ่มเข้ามา
- [ ] ติดตั้ง Vitest พร้อมเทสต์ projection ครอบคลุมทุกชนิดเหตุการณ์ที่ใบนี้ใช้
- [ ] Playwright smoke "เพิ่มผู้สนใจ" ผ่าน
