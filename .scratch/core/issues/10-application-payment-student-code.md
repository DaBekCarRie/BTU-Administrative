# 10: การสมัคร ชำระเงิน และรหัสนักศึกษา

**What to build:** บันทึกได้ว่าคนนี้ยื่นสมัครปีการศึกษาไหน หลักสูตรอะไร ชำระเงินไปแล้วกี่งวด
และได้รหัสนักศึกษาหรือยัง คนเดียวสมัครได้หลายครั้ง (รองรับเคสลาออกแล้วสมัครใหม่)

**Blocked by:** 05

**Status:** done

- [x] บันทึกการสมัครพร้อมปีการศึกษา หลักสูตร และภาค — ปีการศึกษาเป็น**ช่องข้อมูล ไม่ใช่ตารางแยก**
- [x] คนเดียวมีการสมัครได้หลายรายการ และไทม์ไลน์แยกให้เห็นว่าเหตุการณ์ไหนของการสมัครไหน
- [x] บันทึกการชำระแต่ละงวดพร้อมจำนวนเงินและวันที่ แนบสลิปได้
- [x] สถานะการเงินคำนวณจากเหตุการณ์การชำระ พร้อมวันที่ยืนยันล่าสุด
- [x] บันทึกรหัสนักศึกษาเมื่อได้จากสำนักทะเบียน
- [x] เอกสารประจำตัวที่มีอยู่แล้วผูกกับการสมัครใหม่ได้ โดยไม่ต้องอัปโหลดซ้ำ

## ผลการตรวจ

- ยื่นสมัครแล้วสถานะติดตามเป็น "สมัครแล้ว" และล้างวันนัดโทร (หลุดจากคิวเอง)
- คนเดียวสมัครได้หลายรอบ
- บันทึกการชำระแล้วยอดรวมและสถานะการเงินเปลี่ยน พร้อมวันที่ยืนยัน
- **เทสต์ยืนยัน ADR-0002: รักษาสภาพไม่เปลี่ยนสถานะการเรียน** ทั้งใน unit และ e2e
- บันทึกรหัสนักศึกษาแล้วสถานะการเรียนเป็น "เรียนอยู่"
- unit 38/38 · e2e 44/44 · typecheck · lint · build ผ่าน

## การตัดสินใจ

- **สถานะการเงินให้เจ้าหน้าที่เลือก ระบบไม่คำนวณเอง**
  เพราะยอดค่าเทอมจริงของแต่ละหลักสูตรอยู่ที่ฝ่ายการเงิน ทีมเป็นแค่คนบันทึกสำเนา (ADR-0003)
  ถ้าให้ระบบเดาจากยอดที่จ่าย จะผิดทันทีสำหรับคนที่ผ่อนหรือรักษาสภาพ
- **`วันที่ยืนยันสถานะการเงิน` ใช้วันที่ชำระ ไม่ใช่วันที่กดบันทึก**
  เพราะสิ่งที่ยืนยันคือข้อมูลจากฝ่ายการเงิน ณ วันนั้น
- **`ได้รหัสนักศึกษา` ทำให้สถานะการเรียนเป็น "เรียนอยู่"**
  ไม่มีเหตุการณ์ "เริ่มเรียน" แยก เพราะทีมไม่เห็นระบบลงทะเบียนเรียนจริง
  การได้รหัสจากสำนักทะเบียนคือสัญญาณที่ใกล้ที่สุดที่ทีมมี
- หลักสูตรที่สมัครจริงเขียนทับสิ่งที่เคยบอกว่าสนใจตอนเป็นผู้สนใจ
