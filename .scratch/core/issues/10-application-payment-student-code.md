# 10: การสมัคร ชำระเงิน และรหัสนักศึกษา

**What to build:** บันทึกได้ว่าคนนี้ยื่นสมัครปีการศึกษาไหน หลักสูตรอะไร ชำระเงินไปแล้วกี่งวด
และได้รหัสนักศึกษาหรือยัง คนเดียวสมัครได้หลายครั้ง (รองรับเคสลาออกแล้วสมัครใหม่)

**Blocked by:** 05

**Status:** ready-for-agent

- [ ] บันทึกการสมัครพร้อมปีการศึกษา หลักสูตร และภาค — ปีการศึกษาเป็น**ช่องข้อมูล ไม่ใช่ตารางแยก**
- [ ] คนเดียวมีการสมัครได้หลายรายการ และไทม์ไลน์แยกให้เห็นว่าเหตุการณ์ไหนของการสมัครไหน
- [ ] บันทึกการชำระแต่ละงวดพร้อมจำนวนเงินและวันที่ แนบสลิปได้
- [ ] สถานะการเงินคำนวณจากเหตุการณ์การชำระ พร้อมวันที่ยืนยันล่าสุด
- [ ] บันทึกรหัสนักศึกษาเมื่อได้จากสำนักทะเบียน
- [ ] เอกสารประจำตัวที่มีอยู่แล้วผูกกับการสมัครใหม่ได้ โดยไม่ต้องอัปโหลดซ้ำ
