# 11: สถานะการเรียนและเครดิต

**What to build:** บันทึกได้ว่าคนนี้ย้ายเทอม ดรอป กลับมาเรียน หรือลาออก และเห็นสถานะทั้ง 3 มิติ
แยกกันพร้อมวันที่ยืนยันล่าสุด ใบนี้คือที่ที่ ADR-0002 และ ADR-0003 มีผลจริงบนหน้าจอ

**Blocked by:** 10

**Status:** ready-for-agent

- [ ] บันทึกเหตุการณ์ `ย้ายเทอม` `ดรอป` `กลับมาเรียน` `ลาออก` พร้อมเหตุผล
- [ ] ดรอปแล้วเกิด `เครดิต` ค่าเทอมคงเหลือ และเห็นยอดในหน้าคน (ค่าเทอมไม่คืน แต่เก็บไว้ให้)
- [ ] กลับมาเรียนแล้วสถานะการเรียนกลับเป็นปกติ โดยประวัติดรอปยังอยู่ในไทม์ไลน์
- [ ] หน้าคนแสดงสถานะ 3 มิติแยกกัน **แต่ละมิติมีวันที่ยืนยันล่าสุดติดกับค่าเสมอ**
      เช่น `เรียนอยู่ · ยืนยันล่าสุด 3 เดือนที่แล้ว`
- [ ] มีปุ่มยืนยันว่าสถานะการเรียนหรือการเงินยังถูกต้อง เพื่ออัปเดตวันที่ยืนยันล่าสุด
- [ ] **เทสต์: `รักษาสภาพ` ต้องไม่เปลี่ยนสถานะการเรียน**
- [ ] **เทสต์: `ดรอป` ต้องไม่เปลี่ยนสถานะการเงิน**
