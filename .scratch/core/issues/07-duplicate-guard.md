# 07: กันข้อมูลซ้ำ

**What to build:** ระบบเตือนตอนกำลังจะสร้างข้อมูลซ้ำ และรวมสองรายการที่เป็นคนเดียวกันได้
โดยประวัติไม่แตกเป็นสองเส้น (ข้อมูลเดิมมีชื่อซ้ำ 122 แถว เบอร์ซ้ำ 16 แถว)

**Blocked by:** 04

**Status:** ready-for-agent

- [ ] กรอกเบอร์ที่มีอยู่แล้วขึ้นเตือนทันที พร้อมชื่อคนเดิมและลิงก์ไปดู
- [ ] **เตือนแล้วยังบันทึกต่อได้ถ้าเจ้าหน้าที่ยืนยัน** — บางเบอร์ใช้ร่วมกันในครอบครัวจริง
- [ ] หัวหน้าทีมรวมสองรายการเป็นคนเดียวได้
- [ ] หลังรวม เหตุการณ์ของทั้งสองรายการอยู่ในไทม์ไลน์เดียว เรียงตามเวลาที่เกิดจริง
- [ ] การรวมถูกบันทึกเป็นเหตุการณ์ ย้อนดูได้ว่าใครรวมเมื่อไหร่
