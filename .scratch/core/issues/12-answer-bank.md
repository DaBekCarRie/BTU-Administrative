# 12: คลังคำตอบ

**What to build:** ที่เก็บคำถาม–คำตอบที่ทีมใช้ตอบผู้สนใจและใช้เตือนตัวเองเรื่องกฎภายใน
โดยทุกคำตอบบอกได้ว่ายืนยันล่าสุดเมื่อไหร่และโดยใคร

ไม่พึ่งข้อมูลคนเลย — **ทำคู่ขนานกับใบอื่นได้ตั้งแต่ต้น**

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] เพิ่มคำถามพร้อมคำตอบและที่มา
- [ ] ค้นหาคำถามด้วยข้อความภาษาไทย ใช้ trigram เหมือนหน้ารายชื่อ
- [ ] แต่ละคำตอบแสดง **วันที่ยืนยันล่าสุด และชื่อคนที่ยืนยัน**
- [ ] คำตอบที่เก่าเกินเกณฑ์ขึ้นป้ายเตือนว่าควรยืนยันใหม่
- [ ] กดยืนยันว่ายังถูกต้องได้ แล้ววันที่และชื่อผู้ยืนยันอัปเดตโดยไม่ต้องพิมพ์คำตอบใหม่
- [ ] มีป้ายบอกว่า "ตอบผู้สนใจได้" หรือ "ใช้ภายในเท่านั้น" และกรองตามป้ายได้
- [ ] มีคำถามตั้งต้นอย่างน้อย 3 ข้อจากที่ทีมเคยถามจริง เช่น ค่าทำบัตรนักศึกษาแข็ง ·
