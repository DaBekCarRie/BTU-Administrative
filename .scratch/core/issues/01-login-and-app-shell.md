# 01: เข้าสู่ระบบและโครงแอป

**What to build:** เจ้าหน้าที่เปิดเว็บ ล็อกอินด้วยอีเมลและรหัสผ่าน แล้วเห็นโครงเมนู 5 หน้า
พร้อมชื่อตัวเองมุมล่าง คนที่ยังไม่ล็อกอินถูกส่งกลับหน้าเข้าสู่ระบบไม่ว่าจะเปิดเส้นทางไหน

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] ตาราง `staff` ผูกกับผู้ใช้ของ Supabase Auth มี role `staff` และ `admin` เปิด RLS
- [ ] ล็อกอินสำเร็จแล้วเข้าหน้าภายในได้ ล็อกเอาต์แล้วเข้าไม่ได้
- [ ] **เรียก API ตรง ๆ โดยไม่ล็อกอิน ต้องไม่ได้ข้อมูลเลย** — ทดสอบแล้วบันทึกผลไว้ในใบนี้
- [ ] เมนู 5 หน้าแสดงครบและชี้ไปเส้นทางที่มีอยู่จริง
- [ ] ติดตั้ง Playwright และมี smoke test "เข้าสู่ระบบ" ที่ผ่าน
- [ ] `npm run typecheck` และ `npm run build` ผ่าน
