พร้อมชื่อตัวเองมุมล่าง คนที่ยังไม่ล็อกอินถูกส่งกลับหน้าเข้าสู่ระบบไม่ว่าจะเปิดเส้นทางไหน

**Blocked by:** None (can start immediately)

**Status:** done

- [x] **เรียก API ตรง ๆ โดยไม่ล็อกอิน ต้องไม่ได้ข้อมูลเลย** — ทดสอบแล้วบันทึกผลไว้ในใบนี้

## ผลการตรวจ

**RLS — เกณฑ์ "คนนอกต้องไม่ได้ข้อมูลเลย"** ทดสอบกับตารางที่มีข้อมูลจริงอยู่ (ไม่ใช่ตารางว่าง
ซึ่งจะผ่านแบบไม่มีความหมาย):

| ผู้เรียก | ผลลัพธ์ |
|---|---|
| anon (ไม่ล็อกอิน) | `[]` — ไม่เห็นอะไรเลย |
| ผู้ใช้ที่ล็อกอินแล้ว | เห็นข้อมูล staff ตามที่ควรเป็น |
| เรียก `rpc/current_staff_role` ตรง ๆ | `PGRST202` — ไม่เปิดให้เรียกแล้ว |

**Supabase security advisor** เหลือ warning เดียวที่แก้ในโค้ดไม่ได้:
Leaked Password Protection ปิดอยู่ — เป็นสวิตช์ในหน้า Dashboard ต้องเปิดด้วยมือ

**Gate ทั้งหมดผ่าน** typecheck · lint · build · e2e 4/4

## หมายเหตุที่ได้ระหว่างทำ

- ย้าย `current_staff_role()` ไป schema `private` เพราะอยู่ใน `public` แล้ว PostgREST
  เปิดให้เรียกผ่าน `/rest/v1/rpc/` ได้ ทั้งที่ตั้งใจให้ RLS policy ใช้เท่านั้น
- ตรึง `search_path` ของ `set_updated_at()` ตาม advisor
- Supabase บล็อกการสมัครด้วยอีเมลที่โดเมนไม่มี MX record จึง seed ผู้ใช้ทดสอบผ่าน SQL
  (`e2e@btu-admin.dev`) รหัสผ่านอยู่ใน `.env.local` ซึ่งไม่เข้า git
