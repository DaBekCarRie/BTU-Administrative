# 06: คิวโทรวันนี้

**What to build:** เจ้าหน้าที่เปิดระบบตอนเช้าแล้วรู้ทันทีว่าวันนี้ต้องโทรหาใคร
โดยไม่ต้องกรองหรือค้นหาเอง

**Blocked by:** 05

**Status:** ready-for-agent

- [ ] แสดงคนที่ถึงกำหนดโทรวันนี้
- [ ] คนที่เลยกำหนดแล้วแยกให้เห็นชัดจากคนที่ถึงกำหนดพอดี พร้อมบอกว่าเลยมากี่วัน
- [ ] แต่ละแถวแสดงผลโทรครั้งล่าสุดย่อ ๆ และจำนวนครั้งที่ตามมาแล้ว
- [ ] เบอร์เป็นลิงก์กดโทรออกได้จากมือถือ
- [ ] กดบันทึกผลโทรได้จากแถวโดยไม่ต้องเปิดหน้าใหม่
- [ ] คนที่ปิดเคสแล้วไม่ปรากฏในคิว
