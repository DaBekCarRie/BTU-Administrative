## บั๊กจริงที่เจอ — ปุ่ม "พรุ่งนี้" ให้วันที่ของวันนี้

ใช้ `new Date().toISOString().slice(0,10)` หาวันที่ ซึ่ง `toISOString()` แปลงเป็น UTC
**ช่วงเที่ยงคืนถึง 7 โมงเช้าเวลาไทย UTC ยังเป็นเมื่อวาน** ปุ่มลัดจึงให้วันที่เพี้ยนไปหนึ่งวัน

ทีมทำงานถึงสามทุ่มและมีการบันทึกช่วงดึก จะเจอบั๊กนี้จริง
แก้เป็น `toDateInputValue()` ที่ใช้ dayjs กับ timezone Asia/Bangkok
และเพิ่ม unit test 3 เคสที่ตรึงเวลาไว้ตี 1 เวลาไทย เพื่อกันไม่ให้ถอยกลับ

ฝั่ง server action ก็ระบุ offset `+07:00` ลงไปในสตริงวันที่ตรง ๆ
ไม่หวังว่าเซิร์ฟเวอร์จะตั้ง timezone ไว้ถูก (Vercel เป็น UTC)

## เทสต์ที่เคยล้มเพราะตัวเทสต์เอง ไม่ใช่แอป

- กด submit แล้ว `goto` ทันทีโดยไม่รอ server action เสร็จ → เพิ่ม `submitCall()` ที่รอกล่องปิด
- อ่าน `page.url()` ก่อน navigation จบ → เพิ่ม `waitForURL()`
