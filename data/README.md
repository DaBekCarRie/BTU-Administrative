# data/

## `leads-mock.csv` — ข้อมูลผู้สนใจสมมติ

ไฟล์นำเข้าที่แทนชีทจริง 3,180 แถว **ไม่มีข้อมูลส่วนบุคคลของคนจริงอยู่เลย**
ใช้ตั้งต้นระบบใหม่ได้โดยไม่ต้องพึ่งไฟล์ในเครื่องใคร

```bash
npm run import:leads -- --file data/leads-mock.csv --dry-run
```

### สร้างมาอย่างไร

`npm run mock:leads -- --in "<ชีทจริง>.csv" --out data/leads-mock.csv`

- **ชื่อ** แทนทีละคำ คำเดิมได้คำสมมติเดิมเสมอ ชื่อที่ซ้ำกันจึงยังซ้ำเป็นกลุ่มเดิม
  และวรรณยุกต์ที่พิมพ์ซ้ำถูกใส่กลับไปตรงตำแหน่งเดิม
- **เบอร์โทร** แทนด้วยเบอร์สมมติที่คงความยาวและขีดคั่นไว้ เบอร์ซ้ำยังซ้ำ เบอร์ผิดรูปยังผิดรูป
- **ชื่อเจ้าหน้าที่** ทั้ง 17 แบบที่เขียนผิดถูกแทนด้วยชื่อสมมติที่เขียนผิดแบบเดียวกัน
- **หมายเหตุและช่องติดตาม** ถูกสร้างใหม่ทั้งช่อง เพราะในของจริงมีชื่อญาติ ที่อยู่ ไอดีไลน์
  และลักษณะที่ระบุตัวคนได้ ซึ่งล้างด้วย regex ไม่หมด ช่องติดตามคงไว้เฉพาะผู้โทร วันที่ เวลา
  และคำบอกผลการโทร
- **คอลัมน์อื่นไม่ถูกแตะ** — วันที่ คณะ สาขา วุฒิ ภาค ช่องวันที่ให้โทร ยังรุงรังเท่าของจริงทุกเซลล์

ความรุงรังคือสิ่งที่กฎล้างข้อมูลถูกเขียนมาแก้ ถ้าไฟล์นี้สะอาดเกินไป บั๊กที่เคยแก้จะกลับมาเงียบ ๆ
สคริปต์ตรวจตัวเองก่อนเขียนไฟล์ 20 ข้อ ไม่ผ่านข้อเดียวจะไม่เขียน
และสคริปต์นำเข้าอ่านไฟล์นี้ได้ตัวเลขสรุปตรงกับของจริงทุกบรรทัด

การแทนใช้เกลือสุ่มที่ไม่ถูกบันทึก ไฟล์นี้ย้อนกลับไปหาข้อมูลจริงไม่ได้
และรันแต่ละครั้งได้ชื่อสมมติชุดใหม่
